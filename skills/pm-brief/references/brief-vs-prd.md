# 简报与 PRD 的分工

同一份需求的两个投影。判据只有一个：**读者要不要做决定**。要做决定看简报，要执行看 PRD。

## 内容归属

| 内容 | 简报 | PRD | 理由 |
|---|---|---|---|
| 结论（做什么 / 不做什么） | 必须有，各一句 | 有，可展开 | 决定的第一入口 |
| 关键取舍与代价 | 必须有，≤3 条 | 可写进「范围与优先级」 | 决策的核心 |
| 非目标 | 只留最危险的一条 | 全量 | 简报防的是最可能发生的范围蔓延 |
| 一张图 | 必须有 | 可选 | 人靠图建立结构感 |
| 拍板点 | 必须有，带默认选项 | 未决项 | 简报的终点是把决定交回去 |
| 风险与反转信号 | 必须有一条 | 风险章节 | 决定要不要现在做 |
| 验收条件（AC） | 不写 | 全量 | 执行信息，不是决策信息 |
| 指标五要素 | 最多一句结论 | 全量 | 口径属于执行 |
| 背景与证据 | 一句话 | 全量 | 决策人需要结论，不需要通读证据 |
| 数据模型 / 接口 / 字段 | 不写 | 视级别 | 实现信息 |

## 质量判据（可直接当验收用）

把简报单独给一个**没读过 PRD 的人**，限时 2 分钟，看他能否回答：

1. 要做什么？
2. 明确不做什么？
3. 关键取舍是什么，代价是什么？
4. 他需要拍板吗？不拍板会怎样？
5. 最可能怎么错，看到什么该停？

五问全答得出 → 简报合格。任何一问答不出，缺的是对应那一段，不是「写得太简」。

## 常见退化

- **缩写版 PRD**：按章节等比压缩。错在保留了章节结构，没有重组为决策结构。
- **营销稿**：只有价值没有代价。没有代价的取舍等于没做取舍。
- **待办清单**：把拍板项写成问题列表，不给默认选项。等于把决定推回给读者。
- **证据堆**：把 E1–E5 全搬进来。决策人要的是「证据够不够」，不是证据全文。
