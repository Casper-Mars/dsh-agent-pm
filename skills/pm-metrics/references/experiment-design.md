# 实验设计要点

## 先判断能不能做实验

| 条件 | 能做实验 | 只能观察 |
|---|---|---|
| 可随机分组 | ✅ |  |
| 样本量足够 | ✅ |  |
| 变更可回滚 | ✅ |  |
| 强网络效应 / 合规限制 |  | ✅ |

## 关键参数

- **基线**：实验前稳定期的指标值。
- **MDE**：愿意检测到的最小效果，决定样本量。
- **显著性水平**：默认 5%，高风险场景更严。
- **Power**：默认 80%。
- **运行时间**：至少覆盖一个完整行为周期，避免新奇效应。

## 常见偏差

- 提前偷看并停止（peeking）。
- 分流不随机（按用户 ID 尾号但 ID 有规律）。
- 样本污染（同一用户跨组）。
- 只报显著指标，不报全部预设指标。
- 忽略护栏指标。

## 不能做实验时

写清混杂因素、对照方式与结论的可信度限制；不要把观察结论写成因果。
