# 指标树

## 结构

```text
北极星（用户价值 + 商业价值的交集）
├─ 输入指标 A（团队可直接影响）
│  ├─ 子指标 A1
│  └─ 子指标 A2
├─ 输入指标 B
└─ 护栏指标（质量 / 成本 / 信任）
```

## 常见框架

| 框架 | 适用 |
|---|---|
| HEART | 体验类产品： Happiness / Engagement / Adoption / Retention / Task success |
| AARRR | 增长漏斗：获取 / 激活 / 留存 / 收入 / 推荐 |
| 漏斗 | 有明确多步流程的功能 |
| 留存曲线 | 判断是否形成习惯 |

## 规则

- 北极星是用户行为，不是收入数字。
- 每个输入指标必须能对应一个团队动作。
- 护栏指标不可省略：速度、错误率、投诉率、成本。
- 指标数量控制在 5 个以内，多了就看不住。

## 反模式

- 北极星是「DAU」但没有定义活跃。
- 只拆收入，不拆用户价值。
- 指标之间有冲突却没有取舍规则。
- 每个团队一套口径。
