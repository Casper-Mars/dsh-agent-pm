# 实验方案模板

```text
假设：<因为 A，所以 B 指标会变化 C>
目标指标：<主指标，唯一>
护栏指标：<不能被伤害的指标>
分组：<实验 / 对照，比例，分流方式>
样本量：<计算依据：基线、MDE、显著性、power>
最短运行时间：<覆盖行为周期>
判据：
- 成功：<阈值 + 置信区间>
- 失败：<阈值>
- 无结论：<样本不足 / 污染 / 中途变更>
停止规则：<什么情况下提前停止>
风险与伦理：<用户伤害、合规、回滚>
决策人：
```

## 规则

- 主指标只能有一个。
- 判据必须写在实验开始前。
- 中途改方案要记为「新实验」。
- 不显著就写「无结论」，不硬解释。
