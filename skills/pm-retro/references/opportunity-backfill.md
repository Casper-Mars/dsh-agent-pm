# 结论回填

## 回填到哪里

| 结论 | 回填位置 |
|---|---|
| 新机会 | 机会树（OST） |
| 假设被证伪 | 机会树的方案分支标「已否」 |
| 需求优先级变化 | 排序表 |
| 新风险 | PRD 风险章节 / 发布清单 |
| 指标口径问题 | 指标定义 |
| 流程问题 | 复盘改进项 |

## 规则

- 结论必须落到一个具体载体，不留在聊天记录。
- 被否的方案保留，写原因与翻案条件。
- 回填后通知相关决策人。
- 每季度清理一次过期结论。

## 检查

- 一个月后，另一个人能从载体里看懂为什么做 / 不做吗？
- 结论是否可追溯到此前的证据？
- 是否有互相矛盾的结论没有处理？
