# 复盘格式

## 两种场景

| 场景 | 重点 | 时长 |
|---|---|---|
| 版本 / 功能复盘 | 目标是否达成、假设是否成立 | 45 分钟 |
| 事故复盘 | 时间线、根因、影响、改进项 | 60 分钟，无责 |

## 版本复盘议程

1. 目标与基线（5 分钟）
2. 结果数据（10 分钟）
3. 假设逐条判定（15 分钟）
4. 意外与原因（10 分钟）
5. 下一步与负责人（5 分钟）

## 事故复盘议程

1. 时间线（事实，不评价）
2. 影响范围
3. 直接原因与根因
4. 哪些机制失效
5. 改进项（负责人 + 截止）

## 规则

- 对事不对人。
- 每个结论有证据。
- 改进项不超过 3 条，否则没人做。
- 记录存档，下次复盘先看上次改进项。
