# 排序表模板

| 条目 | 问题（一句话） | 证据 | 价值 | 成本 | 风险 | 置信度 | 结论 | 依据 | 重开条件 |
|---|---|---|---|---|---|---|---|---|---|
|  |  | E? | 1–5 | 1–5 | 1–5 | 高/中/低 | Now/Next/Later/不做 |  |  |

## 结论定义

- **Now**：本周期投入，已有明确 owner。
- **Next**：下周期候选，进入条件已写清。
- **Later**：有价值但时机不对，写触发条件。
- **不做**：不在射程，写翻案条件。

## 使用规则

1. 价值 / 成本 / 风险都用相对分，不追求精确。
2. 置信度低的条目，先补证据再排序。
3. 同一行只能有一个结论。
4. 每次排序保留上一版，方便解释变化。
