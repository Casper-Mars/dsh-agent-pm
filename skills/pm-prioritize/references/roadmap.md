# 路线图：Now / Next / Later

## 结构

| 列 | 含义 | 必须写 |
|---|---|---|
| Now | 正在投入 | owner、目标指标、预计完成信号 |
| Next | 下周期候选 | 进入条件、依赖、需要补的证据 |
| Later | 有价值但未排 | 触发条件、复核时间 |
| 不做 | 明确排除 | 原因、翻案条件 |

## 规则

1. 路线图按**结果**组织，不按功能清单组织。
2. 不写具体日期，写「完成信号」：例如「灰度 10% 且核心指标达标」。
3. 每列最多 5–7 项，超出说明没有取舍。
4. Now 列的每一项必须有 owner；没有 owner 的进 Next。
5. 变更路线图要写原因，不静默替换。
6. 每季度复核一次 Later 与不做，防止过期判断。

## 常见错误

- 把路线图做成甘特图。
- 用「Q3 上线」代替结果。
- Next 列塞满，实际没有产能。
- 不做列被删掉，导致重复讨论。
