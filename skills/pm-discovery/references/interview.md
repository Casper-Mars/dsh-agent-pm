# 用户访谈脚本与记录

## 原则

- 问过去，不问未来；问行为，不问偏好。
- 一次一个问题，不给选项，不用「你是不是觉得……」。
- 出现形容词追问数字；出现「大家」追问具体的人。

## 开场

> 我想了解你上次遇到 <问题> 时具体发生了什么，不是让你评价方案。大概 20 分钟，可以吗？

## 五问脚本

1. 最近一次遇到这个问题是什么时候？当时你在做什么？
2. 你当时卡在哪一步？试了哪些办法？
3. 现在怎么凑合解决？用了什么工具或流程？
4. 这一次大概损失了多少时间 / 钱 / 客户？一个月几次？
5. 如果有个新办法，你愿意为它付出什么（钱、迁移、时间）？

## 收尾

- 还有谁遇到过同样的问题？能否引荐？
- 我可以把记录整理后发你确认吗？

## 记录模板

```text
访谈对象：<角色 / 行业 / 规模>（匿名编号）
时间：<日期>
场景：<时间点 + 操作序列 + 卡点>
现有替代：<工具 / 流程 / 不解决>
损失：<可换算量级>
原话：<3–5 句，保留原词>
机会：<用需求语言写，不写方案>
意外：<与预期不同的地方>
证据等级：E?
```
