# 发布分级

| 级别 | 适用 | 要求 |
|---|---|---|
| L0 内部 | 内部工具、无外部用户 | 基本监控 |
| L1 灰度 | 新功能、影响面可控 | 灰度比例、停止条件、回滚 |
| L2 全量 | 影响所有用户、可逆 | 完整清单、值班、客服赋能 |
| L3 高风险 | 计费、权限、数据迁移、合规 | L2 + 法务/安全确认 + 双人复核 + 分批 |

## 判断依据

- 影响多少用户？
- 出错能否回滚？回滚是否丢数据？
- 是否涉及钱、权限、隐私、合规？
- 是否有外部依赖同时变更？

## 规则

- 级别由风险决定，不由工作量决定。
- L3 必须提前演练回滚。
- 级别拿不准时，往高一级处理。
