# 发布清单

## 发布前

- [ ] PRD / AC 已验收通过
- [ ] 发布级别已定（内部 / 灰度 / 全量）
- [ ] 回滚方案：触发条件、步骤、执行人、数据兼容
- [ ] 监控指标与告警已配置
- [ ] 值班人与升级路径已确认
- [ ] 客服 FAQ / 销售话术 / 文档已更新
- [ ] 发布说明已写（用户语言）
- [ ] 合规 / 隐私 / 安全已确认（如涉及）

## 发布中

- [ ] 灰度比例与放量节奏
- [ ] 每阶段观察窗口与停止条件
- [ ] 异常上报渠道

## 发布后 24 小时

- [ ] 核心指标无异常
- [ ] 错误率 / 投诉率无异常
- [ ] 客服问题已归类
- [ ] 决定：继续放量 / 观察 / 回滚

> 清单不替代判断；任何一项「先跳过」都必须记录原因与补偿动作。
