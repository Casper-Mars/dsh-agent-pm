# 一句话需求（`xs`）

适用：用户可观察行为要改，但改法唯一、无取舍、不动对外契约（典型是缺陷修复）。

## 模板

```text
问题：<一句，说清现象与影响>
期望：<一句，说清用户可观察到的结果>
验收：1) <可观察结果> 2) <可观察结果>
级别：xs
```

## 示例

```text
问题：导出 CSV 时文件名带中文会乱码。
期望：导出文件名保留原始标题，不出现乱码。
验收：1) 中文标题下载后文件名正确 2) 纯英文标题不受影响
级别：xs
```

## 规则

- 不超过 5 行；写不满不是缺点，写超了说明该升到 `s`。
- 验收至少 1 条，必须可观察；「正常」「不再报错」不算。
- 不写非目标、指标、分期、数据模型、实现方式。
- 发现需要改对外契约或存在取舍 → 停，升级为 `s` 或 `m` 重写。
