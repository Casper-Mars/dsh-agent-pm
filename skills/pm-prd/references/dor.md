# 交接就绪度（DoR）

PRD 进入开发前逐项检查。任一不满足，不交接。

| # | 项 | 通过线 |
|---|---|---|
| 1 | 问题与证据 | 问题陈述 + 证据等级 + 来源 |
| 2 | 目标 | 指标 / 基线 / 目标值 / 窗口 |
| 3 | 非目标 | 每条能指出挡住的越界行为；无凑数 |
| 4 | 角色与场景 | 具体角色 + 触发场景 + 现有替代 |
| 5 | 范围 | 本期 / 下期 / 延后三列 |
| 6 | 主流程与异常 | 主路径逐步；四类异常有处理 |
| 7 | AC | 三要素齐全，可复现 |
| 8 | 依赖 | 外部依赖、关键假设、最坏情况 |
| 9 | 未决 | 无则写「无」；有则每项有决策人、截止、默认动作 |
| 10 | 验收方式 | 谁来验、用什么数据、在哪验 |

## 不通过时

```text
[阻塞] DoR 6：缺「无权限」异常路径。
要求：补角色无权限时的提示与数据可见范围。
复核：§4 异常表出现该行，且 AC 覆盖。
```

只缺证据、不缺定义时，出「条件版」并写升级条件，不阻塞。
