# 文档三查

`pm-prd` 门禁 10 与交付前使用。交任何文档前逐项过，三项全过才算完成。

## 一、事实查来源与日期

- 通过标准：每个外部数字、用户引语、竞品事实，都能指到来源与日期。
- 不通过：无出处的百分比、无日期的「最新数据」、「据说」「听说」。
- 处理：查不到来源就删掉，或标「未查到来源」，不保留原数字。

## 二、结论查证据与证伪条件

- 通过标准：每条结论后面能指到证据编号；每条结论都写了证伪条件。
- 不通过：结论只有形容词；证据等级低于结论强度；没有翻案条件。
- 处理：降级结论，或补证据；两者都做不到就删掉这条结论。

## 三、范围查非目标与验收可判定

- 通过标准：非目标 / 不做清单非空；每条 AC 有触发条件、可观察结果、判定方式。
- 不通过：没有非目标；AC 里出现「流畅」「良好」「尽量」「大概」。
- 处理：补非目标；把不可判定的 AC 改写成可观察的判定动作。

## 交付前总检查

- [ ] 三查逐项通过
- [ ] 报告四段齐全（结论 / 路径+commit / 逐条验收 / 未决项）
- [ ] commit 真实存在，或明确写「未提交」
- [ ] 失败信息是原文（命令 + 错误文本）
- [ ] 全文无禁用词（见 `language.md`）
