# 变更单模板

```text
变更：<一句话>
提出人 / 日期：
原范围：<引用 PRD 章节>
新范围：<具体变化>
变更原因：<证据或指令来源>
影响：
- 用户可见行为：<有 / 无，说明>
- AC：<新增 / 修改 / 删除>
- 交付时间：<不承诺日期，写相对影响>
- 其他需求：<是否挤占>
选项：
A. 接受，调整范围（代价：<...>）
B. 拒绝，保持原范围
C. 延后到下一期
建议：<A/B/C + 理由>
决策人：<谁> | 截止：<日期>
```

## 规则

- 没有决策人，不变更。
- 不接受「先做，回头补单」。
- 变更后同步更新 PRD 与 AC，保留旧版本。
