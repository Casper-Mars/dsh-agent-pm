# 交接包模板

```text
需求：<名称>（PRD 链接）
本期范围：<做什么>
明确不做：<边界，≥3 条>
验收条件：
- AC1：<前置> → <动作> → <可观察结果>
- AC2：...
未决项：
- <问题> | 决策人：<谁> | 截止：<日期> | 未定前默认：<动作>
依赖：<外部系统 / 团队 / 数据>
验收方式：<谁验、在哪验、用什么数据>
风险：<最坏情况与缓解>
```

## 交接会议（15 分钟）

1. 用 3 分钟讲问题与目标，不讲方案。
2. 逐条读 AC，确认可判定。
3. 读「明确不做」，确认边界。
4. 读未决项，确认谁在什么时候给答案。
5. 记录问题，不现场扩大范围。
