# 产品侧验收（UAT）

## 步骤

1. 准备验收环境与数据，确认与生产一致。
2. 逐条 AC 执行，记录实际结果与证据（截图、日志、数据）。
3. 异常路径单独验：空数据、超时、无权限、重复提交。
4. 回归检查：受影响的旧功能是否仍正常。
5. 结论只有三种：通过 / 有条件通过（列条件）/ 不通过（列失败项）。

## 记录模板

```text
AC1：<描述>
结果：通过 / 失败
证据：<链接或截图>
备注：<与预期的差异>

失败项：
- AC?：<实际 vs 预期> | 负责人 | 修复后复核方式
```

## 规则

- 不看演示代替验收。
- 失败项不标「已知问题」了事，必须记录负责人与复核方式。
- 有条件通过必须写清条件与截止时间。
- 验收通过后不静默改 AC。
