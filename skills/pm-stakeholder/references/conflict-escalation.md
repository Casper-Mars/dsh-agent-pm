# 冲突拆解与升级

## 先分层

| 层 | 问题 | 处理 |
|---|---|---|
| 事实 | 数据/口径不一致 | 对齐来源与口径 |
| 目标 | 各自优化不同指标 | 回到上级目标 |
| 利益 | 资源、预算、责任 | 摆到桌面谈取舍 |
| 关系 | 信任、历史 | 单独沟通，不公开对抗 |

## 拆解步骤

1. 分别复述双方立场与依据，确认理解无误。
2. 找出共同目标，写下来。
3. 区分「事实分歧」与「价值分歧」。
4. 事实分歧用数据解决；价值分歧交决策人。
5. 给出选项与代价，不替任何一方站台。

## 升级

- 升级不是告状，是把决策权交回该拍板的人。
- 升级材料：争议点、双方依据、已尝试的方案、需要谁决定。
- 升级后记录结论与复核点。
- 不在公开场合评价对方动机。
