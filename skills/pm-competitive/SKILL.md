# 市场与竞争

竞品分析的目的不是列功能，而是判断「我们从哪里赢、哪里不跟」。

## Iron Law

> 没有来源的竞品结论，只能标「假设」。

## 什么时候用 / 不用

- 用：新市场进入、定位不清、竞品发布、定价讨论、销售总说「竞品有」。
- 不用：技术选型、专利检索、销售话术撰写。

## 流程

1. **定边界**：为谁、在什么场景、替代谁。替代品包括 Excel、人工和「不解决」。
2. **分市场**：按用户与场景分层，不按功能分；见 `references/market-map.md`。
3. **拆竞品**：只拆与本层用户相关的维度，每条带来源与日期；矩阵见 `assets/competitor-matrix.md`。
4. **找差异**：能力、成本、渠道、数据、生态，选一个能持续的点。
5. **写定位**：为谁 / 替代谁 / 凭什么 / 不做什么；方法见 `references/positioning.md`。
6. **看定价**：定价是定位的一部分，写清价值锚点与付费者。
7. **给结论**：跟 / 不跟 / 差异化，每条写代价。

## 门禁

| # | 门禁 | 通过线 | 不过怎么办 |
|---|---|---|---|
| 1 | 有边界 | 用户 + 场景 + 替代品 | 重写问题 |
| 2 | 有来源 | 每条竞品事实带链接与日期 | 标「假设」 |
| 3 | 有取舍 | 明确不跟的项 | 补「不做」清单 |
| 4 | 定位可检验 | 能说清凭什么赢 | 退回第 4 步 |
| 5 | 定价有锚 | 价值锚点 + 付费者 | 补 |

## 输出契约

竞品矩阵 + 定位陈述 + 跟/不跟清单。定位陈述不超过 100 字。

## 反合理化

| 借口 | 现实 |
|---|---|
| 竞品有我们就得有 | 竞品的用户与成本结构未必和你一样 |
| 这个功能是标配 | 「标配」通常意味着无法差异化 |
| 用户会为便宜买单 | 便宜不是定位，除非你有结构性成本优势 |
| 先抄再改 | 抄来的功能没有对应的场景与证据 |
| 市场很大，总能分到 | 市场大不等于你能赢 |

## 红旗

- 竞品结论来自销售转述且无来源。
- 功能矩阵列了 50 行，没有一行影响决策。
- 定位里出现「最好」「领先」「一站式」。
- 只分析直接竞品，忽略替代方案。
- 定价只算成本，不看价值。
