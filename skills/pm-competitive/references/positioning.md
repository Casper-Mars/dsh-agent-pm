# 定位陈述

## 模板

```text
对于 <目标用户>
他们在 <场景> 下遇到 <问题>
我们的 <产品> 提供 <能力>
与 <替代方案> 不同，我们 <差异点>
因为 <可验证的依据>
我们不做 <明确取舍>
```

## 检查

- 目标用户能否一眼认出「这是在说我」？
- 差异点是否可持续（能力、成本、数据、渠道）？
- 有没有「不做什么」？没有取舍就没有定位。
- 依据是否可验证，不是形容词？
- 竞品能否轻易复制？能就不是定位。

## 反例

- 「一站式解决方案」——没有取舍。
- 「更智能」——不可验证。
- 「面向所有企业」——没有目标用户。
- 「性价比高」——除非有结构性成本优势。
