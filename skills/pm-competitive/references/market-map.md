# 市场地图与用户分层

## 分层维度

- 角色：谁在用、谁在买、谁在批。
- 规模：个人 / 小团队 / 中大型。
- 场景：高频 / 低频、关键 / 边缘。
- 成熟度：手工 / 工具 / 平台。
- 付费意愿：无预算 / 有预算 / 已付费。

## ICP（理想客户画像）

```text
角色：
组织规模：
当前替代：
触发事件：<什么情况下开始找方案>
预算来源：
决策链：<谁用、谁批、谁付>
成功标准：<他们怎么判断值>
```

## 规则

- 先选一个 ICP，不要同时服务所有人。
- 用「当前替代」判断竞争，不只盯同类产品。
- 市场地图每半年复核，进入与退出都要写原因。
